## 🌧️ Sobre o projeto

> **Como a tecnologia pode ajudar no monitoramento de enchentes urbanas?**

O **FloodSense AI** propõe uma solução tecnológica para monitoramento
de níveis de água utilizando sensores conectados, Internet das Coisas
(IoT), armazenamento em nuvem e visualização de dados.

O projeto foi desenvolvido como **protótipo acadêmico**, demonstrando
a integração entre hardware e software em um cenário de monitoramento
de enchentes.
